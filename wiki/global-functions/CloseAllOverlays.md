# CloseAllOverlays() [AI]
Closes every pop-up or menu overlay open on any screen. `[P]`

---

## CloseAllOverlays()

### "[V2.2][Manual] Definition"
```lua
CloseAllOverlays()
```

### Returns
Nothing. `[P]`

### Example `[P]`
```lua
local function tidyUp()
  CloseAllOverlays()
end
tidyUp()
```
- Affects all screens, not just the one the script was started from `[P]`.
