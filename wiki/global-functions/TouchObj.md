# TouchObj() [AI]
Gives you a handle to the first touch object it finds. `[P]`

---

## TouchObj()

### "[V2.2][Manual] Definition"
```lua
TouchObj()
```

### Returns
A handle to the touch object. `[P]`

### Example `[P]`
```lua
Printf("-- touch begin --")
TouchObj():Dump()
Printf("-- touch end --")
```
- Takes no arguments. `[P]`
